# 🔢 Calculator Web App

<p align="center">
  <b>A simple and responsive calculator built using HTML, CSS, and JavaScript 🚀</b>
</p>

---

## ✨ Features

➕ Perform basic arithmetic operations
⚡ Instant calculation results
🧮 Interactive button-based interface
📱 Responsive design
🎨 Clean and user-friendly UI

---

## 🛠️ Tech Stack

* 🧱 HTML5 – Structure
* 🎨 CSS3 – Styling
* ⚡ JavaScript – Logic

---

## ⚙️ How It Works

* Click numbers and operators using buttons
* JavaScript calculates the result
* Output is displayed instantly on the screen
